# Security policy

This is an experimental unsigned boot prototype, not a hardened operating system.
There are no supported stable releases or security-support guarantees yet.
See docs/security.md for the current threat model and limitations.

For a potential exploitable vulnerability, use GitHub's private vulnerability
reporting if enabled on this repository. Do not include exploit details, credentials,
unredacted memory dumps or private device information in a public issue.
If private reporting is unavailable, open only a minimal issue requesting a private
contact channel, without disclosing the vulnerability or sensitive attachments.

Routine non-sensitive boot failures and correctness bugs can use the bug template.
